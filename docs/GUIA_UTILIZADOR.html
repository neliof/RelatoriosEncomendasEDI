EDI

Guia de Utilizador

Bem-vindo ao Relatórios Encomendas EDI, uma ferramenta profissional para gerir e monitorizar o processamento de ficheiros de encomendas em formato EDI.

Este guia explica como utilizar cada funcionalidade da aplicação, passo a passo. Não requer conhecimentos técnicos — basta seguir as instruções.

O que faz esta aplicação?

A aplicação monitora automaticamente ficheiros de encomendas que chegam, processa-os e agrupa-os por cliente ou fornecedor. Mostra um resumo visual do estado de cada envio e permite configurar como e quando deve processar cada ligação.

Resumo (Dashboard)

O ecrã inicial mostra um resumo rápido do estado geral.

O que vejo?

  1. Título e marca — No topo, o nome da aplicação e o botão Atualizar (girará enquanto carrega dados).
  2. Cartões de métricas — Quatro blocos numerados:
    • Total de Ficheiros — quantos ficheiros foram descobertos no total.
    • Enviados — quantos foram processados com sucesso.
    • Confirmados — quantos chegaram ao destino (se a confirmação estiver ativa).
    • Erros — quantos falharam.
  3. Clientes — Uma tabela mostrando cada cliente (origem dos ficheiros) e quantos ficheiros tem. Clique numa linha para ver mais detalhe.
  4. Fornecedores — Semelhante, mas para ficheiros saídos (se houver).
Dica: Clique no botão Atualizar se os números não corresponderem ao que espera. A aplicação refresca automaticamente cada 5 segundos.

Relatórios

Nesta aba, vê um resumo detalhado e filtrável de cada ficheiro processado, agrupado por cliente ou fornecedor.

Como filtrar por data?

  1. Clique na aba Relatórios no menu esquerdo.
  2. No topo, verá dois campos de data:
    • De — data inicial do intervalo.
    • Até — data final do intervalo.
  3. Edite qualquer dos campos e clique fora (ou pressione Enter) — a tabela atualiza-se automaticamente.
  4. Para repor o filtro, limpe os campos ou clique Limpar Filtros.

O que mostram os números?

Cada linha da tabela representa um cliente ou fornecedor e mostra:

  • Nome — nome do cliente ou fornecedor.
  • Total — quantos ficheiros tem no período escolhido.
  • Enviados — quantos foram processados.
  • Erros — quantos falharam (vermelho se houver).
  • Último contacto — quando foi o envio mais recente.
Se clicar numa linha, abre um painel com todos os ficheiros desse cliente, um a um, e os detalhes de cada (data, estado, mensagens de erro se houver).

Configuração

Aqui configura como a aplicação processa ficheiros — quais as ligações, credenciais, agendamento e localização das pastas.

Nova Ligação

  1. Clique na aba Configuração.
  2. No painel Nova Ligação, preencha:
    • Nome — identificador único (ex: "FTP_Cliente_A").
    • Protocolo — FTP, SFTP ou Local (pasta).
    • Tipo — "Receber" (ficheiros que chegam) ou "Enviar" (ficheiros que saem).
    • Host — endereço do servidor (ou deixe em branco para Local).
    • Porta — porta FTP/SFTP (21 ou 22 normalmente).
    • Utilizador — nome de utilizador.
    • Pasta Local — caminho na máquina local onde armazena ficheiros.
  3. Clique Criar. Verá a nova ligação na lista abaixo.
Atenção: Precisa de permissões administrativas (password) para criar, alterar ou eliminar ligações.

Editar Credenciais

  1. Na lista Ligações Configuradas, localize a ligação.
  2. Clique no ícone ⚙ (engrenagem) ou no botão de edição ao lado do nome.
  3. No painel Editar Credenciais, altere:
    • Host
    • Porta
    • Utilizador
    • Password (deixe em branco para não alterar)
  4. Clique Guardar.

Agendar Processamento

Defina com que frequência a aplicação processa ficheiros de cada ligação.

  1. Na lista Ligações Configuradas, clique em Agendar ao lado da ligação.
  2. No painel Agendar Ligação, escolha:
    • Ativado — marca a caixa para ligar/desligar este agendamento.
    • Frequência — Diariamente, De Hora em Hora, ou A cada X minutos/horas.
    • Hora / Minuto — se diário, a que hora.
  3. Clique Guardar. A aplicação processa automaticamente nos horários escolhidos.
Dica: Para testar rapidamente, escolha "A cada 1 minuto" e aguarde. Verá os ficheiros processados no ecrã Resumo.

Manutenção — Limpar Base de Dados

Se quiser recomeçar do zero (para testes), pode eliminar todos os registos processados.

  1. No painel Manutenção, clique Limpar Base de Dados.
  2. Aparecerá uma caixa a pedir confirmação. Digite exatamente DELETE_ALL_DATA.
  3. Clique Confirmar. Todos os registos serão apagados e a base de dados reinicializada.
Cuidado: Esta ação é irreversível. Certifique-se de que não precisa dos dados históricos.

Generix Mailbox — Localização

Se usa Generix Mailbox, indique onde estão as pastas de entrada e saída.

  1. No painel Configurações Gerais, procure o campo Localização Generix Mailbox.
  2. Cole o caminho completo (ex: C:\Users\Utilizador\Documents\Generix).
  3. Clique Guardar. A aplicação usa esta localização para descobrir pastas de "Recebidos" e "Enviados".
